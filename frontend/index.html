How to use PrioritySat
A decision-support workflow, not a physical control console.

01 · Discover

Open Network Explorer, filter degraded nodes, and inspect generated telemetry and connections.

02 · Compare

Use Route Planner to compare latency and availability trade-offs between endpoints.

03 · Stress-test

Run a what-if scenario in Simulation Lab and use its results to reconsider the route.

04 · Audit

Review the Activity Log to understand what the demo simulation changed.

Data integrity statement
Read before interpreting any values.

Every satellite position, telemetry reading, metric, route estimate, alert, and simulation output in this build is generated DEMO DATA. A connected backend confirms only that this local API responds; it does not verify satellite data. The app does not issue physical satellite or ground-station commands.
